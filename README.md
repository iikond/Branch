# Branch

> Independent parts. One system.

Branch — open-source платформа для совместной работы, объединяющая общение, задачи, заметки, мероприятия и рабочее пространство в одну систему.

Проект создаётся как набор независимых компонентов, которые могут работать отдельно, но при необходимости взаимодействуют друг с другом через API и общие интерфейсы.

## Идея

Вместо одного огромного приложения Branch состоит из отдельных частей:

* 💬 **Chats** — личные сообщения, группы и уведомления
* ✅ **Tasks** — задачи для себя и других пользователей
* 📝 **Notes** — заметки и сохранённая информация
* 📅 **Events** — мероприятия и связанные уведомления
* 🎨 **Board** — единое рабочее пространство
* 🧩 **Extensions** — расширения и интеграции

Главная идея — **модули независимы, но контекст между ними не теряется**.

Например, сообщение в чате может превратиться в задачу, задача может быть связана с мероприятием, а всё это отображаться на общей доске.

## Почему Branch?

Название отсылает к Git branches.

Каждая часть системы может развиваться независимо, иметь собственную логику и даже быть заменена без необходимости переписывать весь проект.

При этом отдельные ветви могут объединяться, создавая единый пользовательский опыт.
